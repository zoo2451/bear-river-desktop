Bear River Gage Explorer (Desktop)

A Tkinter desktop app that maps the USGS stream gages in the Bear River basin (HUC 1601, in Utah, Idaho, and Wyoming). Click a gage to see its drainage area, its latest flow, and a daily hydrograph with statistics.

This is a Python desktop app, so it runs on your computer, not in the browser. Download it and start it with python app.py (steps below).
Download app.py requirements.txt spec.md prompts.md README.md

Install and run

  1. Install Python 3.10 or newer from python.org. On Windows, check "Add Python to PATH" and keep "tcl/tk" selected.
  2. Download app.py and requirements.txt into one folder (or clone this repository).
  3. In a terminal in that folder, run: 
    python -m pip install -r requirements.txt
python app.py

The app needs internet to download live USGS data and map tiles. Without it, use File > Open Session to view a session saved earlier.

What it does

  • Map: the basin boundary, with active gages (reported in the last 7 days) as blue dots. A checkbox also shows the ~300 historical sites in gray.
  • Gage list: a sortable table with site number, name, and latest flow (cfs).
  • Info panel: name, site number, county and state, drainage area (mi²), latest flow (cfs), and the reading time in Mountain Time, with a link to the gage's USGS page.
  • Hydrograph and statistics: daily mean discharge with the mean flow Q̄, the number of days n, the peak and minimum, and the runoff volume V = 1.98347 × ΣQi acre-ft.
  • Downloads run in a background thread, so the window never freezes.

Features added (not in the web version)

  1. Interactive hydrograph toolbar: pan, zoom, and save the plot as PNG/PDF; a period dropdown (30, 90, 365, or 730 days) and a log-scale toggle.
  2. Export to CSV/Excel: save the selected gage's daily flow and statistics, or the table of all gages, as .csv or .xlsx.
  3. Save/open session: store all downloaded data in a .json file and reopen it later without internet, for field use or a dated snapshot for a report.

Data

All data comes from the USGS Water Data API and the USGS Watershed Boundary Dataset. Map tiles are from OpenStreetMap. Values USGS marks "Provisional" may change.
